## Proyek yang bisa dicoba

### Simplify Worksheet

Dua file Excel masuk: Data Sales dan Master Mobil. Aplikasi mengisi nomor polisi sesuai aturan armada, menandai data yang konflik, lalu menyiapkan file hasil untuk diunduh. Pengolahannya berjalan di browser pengguna.

Pada berkas contoh berisi 5.893 baris, 214 grup mengikuti data yang sudah ada dan 470 grup dialokasikan dari Master Mobil. Sebanyak 116 grup yang belum dapat dialokasikan tetap kosong dan dilaporkan, bukan dipaksa terisi.
